**Как обойти блокировки Роскомнадзора, сохранить доступ к Госуслугам и Сбербанку, и перестать выключать VPN каждую минуту.**

В условиях, когда российские власти во главе с Роскомнадзором (РКН) отчаянно пытаются изолировать рунет от остального мира, использование VPN стало базовой потребностью для выживания в сети. Государство блокирует независимые медиа, социальные сети, мессенджеры и даже протоколы VPN (OpenVPN, WireGuard, IPsec), пытаясь загнать граждан в цифровой ГУЛАГ. 

Но у этой безумной цензуры есть обратная сторона: многие российские сервисы (банки, Госуслуги, маркетплейсы, стриминги) **блокируют доступ с зарубежных IP-адресов**. В итоге пользователи вынуждены постоянно включать и выключать VPN, что жутко раздражает.

Этот репозиторий решает проблему раз и навсегда. Здесь собран **готовый JSON-список крупнейших российских сайтов для функции раздельного туннелирования (Split Tunneling) в Amnezia VPN**.

## 🆕 Октябрь 2026: список наконец-то работает при импорте

Если раньше вы импортировали список, а сайты всё равно шли через VPN ([issue #4](https://github.com/kozlovartem20201/amnezia-vpn-russia/issues/4)) — **скачайте файл заново и импортируйте с заменой**.

**В чём была проблема.** В старом файле были только имена сайтов с пустым полем `"ip": ""`. Amnezia при **импорте** не определяет IP-адреса доменов (это происходит только при ручном добавлении сайта), а для AmneziaWG, WireGuard и для всех протоколов на Android и iOS маршруты строятся **только по IP**. В итоге список импортировался, но ничего не исключал, и весь трафик шёл через VPN.

**Что изменилось:**
- у каждого домена теперь есть актуальные IP-адреса (поле `ip` для Amnezia 4.8 и `ips` для Amnezia 5.x);
- добавлены подсети крупных компаний (Яндекс, VK, Сбер, Т-Банк, Альфа, ВТБ, НСПК, Ozon, Wildberries, Avito и др.), которые не устаревают при смене IP;
- в список попадают только российские адреса: сайты за Cloudflare, AWS и другими зарубежными CDN не исключаются, иначе мимо VPN пошли бы и заблокированные сайты на тех же IP;
- удалены сайты, **заблокированные в РФ** (meduza.io, thebell.io, novayagazeta.ru и др.): мимо VPN они просто не открывались;
- удалены зарубежные сервисы, которые сами блокируют российских пользователей (booking.com, jetbrains.com, coursera.org и др.), и мёртвые домены;
- добавлены важные поддомены: статика Госуслуг `gu-st.ru`, `online.sberbank.ru`, `online.vtb.ru`, картинки Ozon/Wildberries/Avito и т.д.;

## 🚀 Что такое раздельное туннелирование и зачем оно нужно?

**Раздельное туннелирование (Split Tunneling)** — это функция VPN-клиента, которая позволяет разделить ваш интернет-трафик на два потока. 

С помощью нашего файла конфигурации вы можете настроить Amnezia VPN так, чтобы:
1. **Весь заблокированный и зарубежный трафик** (Instagram, Twitter, YouTube, независимые СМИ) шел через защищенный зашифрованный туннель вашего зарубежного сервера.
2. **Трафик к российским сервисам** (Сбербанк, Госуслуги, Wildberries, Яндекс) шел напрямую через вашего провайдера, минуя VPN.

### Преимущества этого решения:
- **Никаких капч и блокировок от банков:** Российские банки больше не будут блокировать ваши переводы из-за "подозрительного входа из Нидерландов".
- **Экономия трафика на сервере:** Тяжелый контент с Кинопоиска, VK Видео или RuTube не будет расходовать лимит трафика на вашем VPS.
- **Максимальная скорость:** Локальные сайты будут открываться с максимальной скоростью вашего провайдера без задержек на шифрование и маршрутизацию через другую страну.
- **Бесшовный опыт:** Вы включаете Amnezia VPN один раз и забываете о нем.

## 🛠️ Инструкция по настройке Amnezia VPN

Подходит для Amnezia VPN **4.8.x и 5.x** на Windows, macOS, Linux, Android и iOS, для любого протокола.

### Шаг 1: Скачайте файл
👉 **[Скачать tunneling-list.json](https://raw.githubusercontent.com/kozlovartem20201/amnezia-vpn-russia/main/tunneling-list.json)**

Откроется страница с текстом — это нормально. Сохраните её как файл: на компьютере **Ctrl+S** (или «Сохранить как…»), на телефоне — «Поделиться» → «Сохранить в Файлы». Имя файла должно заканчиваться на `.json`.

### Шаг 2: Импорт в Amnezia VPN
1. **Отключите VPN.** Пока соединение активно, Amnezia не даёт менять настройки раздельного туннелирования.
2. Откройте **Настройки** → **Соединение** → **Раздельное туннелирование сайтов** и включите переключатель.
3. В пункте **Режим** выберите **«Адреса из списка не должны открываться через VPN»**. Это важно сделать *до* импорта: у каждого режима свой список.
4. Нажмите кнопку **⋮** внизу экрана, рядом с полем «веб-сайт или IP» → **Импорт** → **«Заменить список с сайтами»**.
5. Выберите скачанный `tunneling-list.json` и дождитесь сообщения «Импорт завершён».
6. Подключите VPN.

### Шаг 3: Проверьте, что всё работает
С включённым VPN откройте **[yandex.ru/internet](https://yandex.ru/internet)** — там должен быть IP-адрес вашего **домашнего провайдера**. А на любом зарубежном сервисе проверки IP (например, [ifconfig.me](https://ifconfig.me)) — IP вашего **VPN-сервера**. Если и Яндекс показывает IP сервера, смотрите раздел «Частые проблемы».

### Шаг 4: Обновляйте список раз в месяц
IP-адреса сайтов со временем меняются. Раз в месяц скачивайте свежий файл и импортируйте его так же, через **«Заменить список с сайтами»**. Если вы добавляли свои сайты вручную, используйте «Добавить импортированные сайты к существующим».

### Для администраторов VPN: как раздать настройки семье и друзьям
Список сайтов хранится **в настройках приложения**, а не в профиле подключения, поэтому через «Поделиться» (файл `.vpn` или QR-код) он **не передаётся**. Отправьте пользователям ссылку на файл из шага 1 и эту инструкцию — импорт займёт минуту.

> Не раздавайте для этого «Резервную копию» Amnezia: в ней хранятся все ваши серверы и ключи доступа к ним.

## ❓ Частые проблемы

**Импортировал, но всё равно всё идёт через VPN.**  
Скорее всего, у вас старая версия файла без IP-адресов. Скачайте файл заново и импортируйте через «Заменить список с сайтами». Проверьте, что режим — «Адреса из списка не должны открываться через VPN», а импорт делался при отключённом VPN.

**Пишет «Сервер по умолчанию не поддерживает раздельное туннелирование».**  
Так бывает у конфигураций AmneziaWG/WireGuard, где в самом конфиге уже задано, какие адреса идут через VPN. Раздельное туннелирование сайтов работает, только если в конфиге стоит `AllowedIPs = 0.0.0.0/0, ::/0` — именно с `::/0`: при одном `0.0.0.0/0` клиент молча игнорирует список. Попросите администратора выдать полный конфиг или поправьте строку `AllowedIPs` в `.conf` и импортируйте его заново.

**Банковское приложение на Android всё равно ругается на VPN.**  
Многие приложения (Сбер, Т-Банк, Госуслуги, Max) проверяют не IP-адрес, а сам факт включённого VPN в системе, и список сайтов тут не поможет. Используйте **Настройки → Соединение → Раздельное туннелирование приложений** в режиме «Приложения из списка не должны работать через VPN» и добавьте туда эти приложения. Если приложение всё равно видит VPN, остаётся только отключать VPN на время работы с ним.

**Сайт есть в списке, но не открывается.**  
Некоторые российские сайты работают через Cloudflare или другие зарубежные CDN. Их IP-адреса делят тысячи сайтов, в том числе заблокированных, поэтому такие адреса намеренно не исключаются из VPN. Если сайт перестал работать по другой причине, [создайте issue](../../issues/new/choose) — шаблон подскажет, что указать.

**Работает ли IPv6?**  
Нет: раздельное туннелирование в Amnezia поддерживает только IPv4-адреса, поэтому и в списке только IPv4.

**Какие сайты увидят мой настоящий IP?**  
Все российские сервисы из списка — в этом и смысл. Учтите, что подсети Яндекса и VK исключены целиком, поэтому их счётчики и виджеты на зарубежных сайтах тоже увидят ваш домашний IP.

## 🛑 Почему это важно именно сейчас?

Российские власти (Минцифры, РКН) рассылают методички госкомпаниям с требованием выявлять и блокировать IP-адреса VPN-сервисов. Они пытаются анализировать трафик через ТСПУ (Технические средства противодействия угрозам) и блокировать целые подсети хостинг-провайдеров.

Используя **AmneziaWG** (протокол, маскирующий VPN-трафик под обычный мусорный трафик) в связке с **раздельным туннелированием**, вы:
1. Не «светите» IP-адрес своего сервера российским сервисам: банки, маркетплейсы и госсайты видят обычный домашний IP, а не адрес зарубежного VPS, который они могут передать в РКН.
2. Не даёте поводов пометить ваш аккаунт в банке или на Госуслугах как «вход из-за рубежа через VPN».

Свободный интернет — это базовое право человека. Никакие чиновники не должны решать, какие сайты вам читать и какими сервисами пользоваться.

## 🤝 Как помочь проекту?

Интернет меняется каждый день: появляются новые сервисы, старые меняют домены. Если важный российский сайт (банк, магазин, госсервис) не открывается с включённым VPN:

1. Откройте **[Issue](../../issues/new/choose)** по шаблону «Сайт не открывается».
2. Или сделайте **Pull Request**: добавьте домен в [`sources/domains.txt`](sources/domains.txt) в нужную категорию. **Сам `tunneling-list.json` руками не правьте** — он генерируется автоматически.

Правила для списка:
- только российские сервисы, которым нужен российский IP или которые быстрее работают напрямую;
- никаких сайтов, заблокированных в РФ, и зарубежных сервисов — без VPN они не откроются;
- поддомены добавляйте отдельно, если у них свои IP (`online.sberbank.ru` ≠ `sberbank.ru`); вариант `www.` проверяется автоматически.

### Как устроена сборка

| Файл | Что это |
| :--- | :--- |
| [`sources/domains.txt`](sources/domains.txt) | Домены по категориям — основной файл для правок. |
| [`sources/asn.txt`](sources/asn.txt) | ASN крупных компаний: их подсети попадают в список целиком. |
| [`sources/protection-asn.txt`](sources/protection-asn.txt) | Российские анти-DDoS сервисы с зарубежной регистрацией (DDoS-Guard, Qrator, StormWall): из них берутся только адреса доменов из списка. |
| [`sources/cidr.txt`](sources/cidr.txt) | Подсети, добавленные вручную. |
| [`scripts/build.py`](scripts/build.py) | Сборщик: резолвит домены через DNS-over-HTTPS, отбрасывает зарубежные адреса, собирает JSON. Нужен только Python 3.9+. |
| `tunneling-list.json` | Готовый файл для Amnezia (генерируется). |
| `ru-subnets.txt` | Те же подсети простым списком — для роутеров, sing-box, Xray и других клиентов (генерируется). |

Собрать локально:
```bash
python scripts/build.py --report build-report.md
```

В отчёте `build-report.md` видно, какие домены перестали существовать или переехали на зарубежные CDN. GitHub Actions пересобирает список каждый понедельник и после каждого изменения в `sources/`.
